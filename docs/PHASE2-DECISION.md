# 2차(파인튜닝) 보류 결정 — 2026-10-29

> **결정**: 프로젝트를 **v0.1(1차분)에서 멈추고 2차 파인튜닝은 진행하지 않는다.** 현재 `jaewon-stt`는 prompt 튜닝만 된 학습 전 모델이며, 비교 테스트 페이지(`web/stt-test`)로 1차 결과를 확인할 수 있는 상태로 마무리한다.

## 1. 요약

| 구분 | 내용 |
| --- | --- |
| 완료 | 1차: 2단계 설계, `jaewon-stt`/`jaewon-tts`, 평가 도구, 합성 진단 + 실제 제주어 기준선, 비교 테스트 페이지 |

| 재개 조건 | [5장](#5-재개-조건) 참고 |

## 2. 2차를 진행했을 때의 비용 (추정)

가정: 실음성 방언 약 300시간(권역당 약 60시간) + 표준어 약 100시간 + 기술 용어 합성 ≤100시간, Whisper large-v3-turbo LoRA, 실험 3~5회.

| 항목 | 최소 | 권장 | 여유 |
| --- | --- | --- | --- |
| GPU 학습 (A100/L40S급, 시간 과금) | 약 6만 원 (30 GPU시간) | 약 15만 원 (60시간) | 약 42만 원 (120시간, large-v3 포함) |
| 학습 서버 스토리지·전송 | 약 3만 원 | 약 7만 원 | 약 15만 원 |
| 서빙 테스트 GPU (L4급, 비교·카나리 기간) | 약 1만 원 | 약 5만 원 | 약 10만 원 |
| TTS 용어 합성 · 평가 호출 · AI Hub 데이터 | 0원 | 0원 | 약 1만 원 |
| **합계 (일회성)** | **약 10만 원** | **약 30만 원** | **약 70만 원** |
| 3차 상시 서비스 (별도) | 요청 시 기동(서버리스) 월 수만 원 ~ 상시 L4 월 약 50~80만 원 | | |

> 가격은 일반적인 클라우드 GPU 시세 기준 추정이며 결정 시점에 업체별 실제 가격 확인이 필요하다.

## 3. 2차를 진행했을 때의 기간 (추정)

| 주차 | 작업 | 사용자 필요 조치 |
| --- | --- | --- |
| 1주 | AI Hub 신청·승인(보통 1~7일), 데이터 수신·정리, 4개 권역 기준선 | AI Hub 신청, GPU 업체 계정·결제 |
| 2주 | 학습 데이터 구성(표기 통일, 화자 단위 분리), 용어 합성 | TTS 학습 사용 약관 확인 |
| 3주 | 파인튜닝 3~5회(회당 약 3~10시간), 정규화 개선 | 중간 결과 확인 |
| 4주 | 비교 평가, 테스트 페이지 연결, v0.2 | 최종 확인 |
| +1~2주 | 승인 지연·다운로드·추가 실험 여유 | — |

**총 4~6주.** 실제 GPU 사용은 2~5일이고, 대부분은 데이터 승인·수신·정리 시간이다. 권역별 데이터가 수백 GB라 가정용 회선 다운로드만 며칠이 걸릴 수 있다.

## 4. 로컬 PC(CPU) 학습 검토

외부 GPU 비용을 피하기 위해 로컬 PC의 CPU 학습도 검토했다.

| 항목 | 값 |
| --- | --- |
| 하드웨어 | AMD 8코어급 CPU (Radeon 780M 내장 그래픽), RAM 32GB, NVIDIA GPU 없음 |
| 실효 연산 | 약 0.4~0.5 TFLOPS (A100의 1/100 이하) |
| 학습 단가 | large-v3-turbo 30초 구간 1개 학습 ≈ 6 TFLOP → **약 12~15초/구간** (Whisper는 짧은 발화도 30초 창으로 처리) |
| 데이터 규모 | 500시간 ≈ 30초 구간 6만 개 |

| 방식 | 1 epoch | 완료까지 (3 epoch + 실험) | 기대 효과 |
| --- | --- | --- | --- |
| A. 2차 계획 그대로 (전체 LoRA, 500시간) | 약 9일 | **4주 ~ 2개월** | 목표 수준 |
| B. 인코더 고정 + 디코더만 학습 (인코더 출력 사전 계산, 디스크 약 230GB) | 사전 계산 3~4일 + 학습 약 5시간 | **약 5~7일** | 기술 용어·방언 표기 습성에 유효, 억양 적응은 약함 |
| C. 데이터 50시간으로 축소 (A 방식) | 약 1일 | 약 4~6일 | 일부 개선, 과적합 위험 |
| D. whisper-small 전체 학습 | 약 1.5일 | 1~2주 | 기본 한국어 성능이 낮아 비추천 |
| 참고: 클라우드 A100 | 약 2.5시간 | 1~2일 | 목표 수준, 약 15만 원 |

> 이론 계산 추정치(±2배)이며 실측하지 않았다.

**CPU 학습을 택하지 않은 이유**

1. **운영 서비스 영향** — 이 PC가 Kubernetes 클러스터 전체(GitLab, Dify, MDAI, LiteLLM 등)를 구동한다. 수 일~수 주간 CPU를 포화시키면 서비스 응답이 느려지거나 끊긴다. 코어 제한·야간 실행 시 기간은 더 길어진다.
2. **기간 대비 효과** — 현실적인 B 방식도 1주가 걸리고, 억양·고유 어휘 개선(인코더 학습)은 포기해야 한다.
3. **내장 GPU 미사용** — Radeon 780M은 Windows에서 ROCm 공식 지원 대상이 아니고, DirectML 학습은 불안정해 대안이 되지 못한다.
4. **데이터 선행 조건은 동일** — CPU로 학습해도 AI Hub 데이터 신청·약관 확인은 똑같이 필요하다.

## 5. 재개 조건

다음 중 하나가 충족되면 2차를 재개할 수 있다. 1차의 평가 도구·평가셋·그래프 스크립트가 그대로 재사용되므로 기준선과의 비교는 바로 가능하다.

| 조건 | 재개 경로 |
| --- | --- |
| 외부 GPU 예산(권장 약 30만 원) 승인 | 원래 2차 계획 (4~6주) |
